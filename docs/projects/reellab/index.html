ReelLab — Personalized Recommendations

Working prototype

A movie recommendation lab with a locally trained model, editable taste profiles, and a measured comparison against popular picks.

Working local research prototype. The model, interface, and evaluation are implemented. The measured comparison does not establish an improvement over the popularity baseline.

Explore the screenshots, walkthrough and measured results below. The interactive application currently runs locally; contact me for a demonstration.

Build a taste profile

Search the historical movie catalog and rate films from 1 to 5. The model fits a new profile against frozen movie factors, excludes rated films, and explains similar learned taste patterns. Ratings can be changed or cleared.

02 / Engineering

Engineering evidence

Problem and scope

A recommender should be assessed against a simple alternative. This project asks whether learned collaborative patterns improve movie ranking over popularity, and how much rating history is needed for personalization.

My role and contribution

Implemented a NumPy matrix-factorization model, new-profile fitting, a local API, a responsive review interface, chronological evaluation, and tests. The project includes reproducible training scripts, a model card, saved results, and a CI workflow definition.

Architecture and data flow

The browser sends a rating profile to a local Python service. Frozen 12-dimensional movie factors produce the ranking; an optional genre-based step reranks for variety. The browser stores the profile locally. Training and evaluation run separately from serving.

Technology choices and tradeoffs

Use popularity when there is no profile. Select regularization using validation data and keep the final test separate. Show support counts and avoid interpreting model estimates as confidence. Keep the source code and research dataset private while sharing aggregate evaluation findings.

Results and evaluation

On 10,000 held-out ratings, personalized NDCG@10 was 0.1933 versus 0.1929 for popularity across 147 eligible users. The paired 95% bootstrap interval for the difference was −0.0073 to 0.0074. With at most three training ratings, NDCG@10 fell to 0.1820. These findings do not establish a benefit from personalization; 95 test users had no training history and received the popularity fallback.

Limitations and next steps

MovieLens 100K reflects 1997–98 preferences. Unrated films are unknown, and new items are excluded from this model. The interactive variety control has no claimed accuracy benefit. Tests and a local demo are complete; public hosting, a recorded walkthrough, and an online user study are not included.
